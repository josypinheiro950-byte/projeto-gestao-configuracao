# Projeto de Gestão de Configuração

## Objetivo
Projeto demonstrativo para a atividade prática de Gerenciamento de Configuração. O repositório contém artefatos simples que podem ser modificados e versionados com Git e GitHub.

## Artefatos
- `novo.py`: exemplo de funcionalidade inicial.
- `nova_funcionalidade.py`: funcionalidade adicionada durante a prática.
- `CHANGELOG.md`: registro das alterações.

## Como executar
Com Python 3 instalado, execute:

```bash
python novo.py
python nova_funcionalidade.py
```

## Fluxo de versionamento
1. Clonar o repositório com `git clone URL_HTTPS_DO_REPOSITORIO`.
2. Modificar ou criar arquivos.
3. Conferir as alterações com `git status`.
4. Preparar as alterações com `git add .`.
5. Registrar com `git commit -m "Descreve a alteração"`.
6. Enviar ao GitHub com `git push`.
